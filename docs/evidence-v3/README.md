# 验收证据说明

本目录区分两类证据，发布时请注意隐私边界。

## 公开（仓库内）

- `SPIKE-RESULT.md`：spike 与实机审查的技术结论，不含真实会话正文。
- `v3-*.png`：隔离 `DSH_HOME` + 独立端口 3092 的 e2e 截图，使用合成会话/测试数据。
- `01-*` ~ `07-*`：spike 截图（如含旧 UI，仅作历史资料）。
- `v3-result.json`、`probe-result.json`：隔离 e2e / 探针的机器结果。

仓库内的截图已统一裁掉左侧会话栏/头像（仅保留画板与 composer 区域），
`v3-11-narrow-viewport.png` 额外遮住了左下角头像/用户名，避免公开身份信息。

## 本地保留（不进入公开 Git）

- `live-*.png`：真实 3080 的实机截图，包含真实会话标题、用户指令、模型思考等上下文。
  这些文件已在 `.gitignore` 中排除，只作为本机验收证据保留。
- 如果公开发布需要截图证据，请重新生成脱敏版本（裁掉左侧会话列表、顶部栏和聊天正文，
  只保留画板/composer 区域），不要直接提交原始 `live-*.png`。

对应文档中的 `live-*.png` 链接仅在本机工作区有效；公开仓库读者请以
`SPIKE-RESULT.md` 的文字结论和隔离 e2e 证据为准。
