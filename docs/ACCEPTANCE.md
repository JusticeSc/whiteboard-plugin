# 画板 v2 — 人工验收清单（重启 3080 之后）

> **历史文档（2026-11-04）**：这是 v2（`conversation.view` + 画布内 AI 卡片）的验收清单，
> 已被 [ADR-0003](adr/0003-canvas-agent-bridge.md) / [DECISIONS.md](DECISIONS.md) 的设计取代。
> v3 的验收清单见 [`ACCEPTANCE-v3.md`](ACCEPTANCE-v3.md)；本文件仅作 v2 回归参考。

目标：10 分钟内确认"数据在 Host、会话是视图、AI 一步可撤销"三件事成立。
勾选方式：每条都写了**期望**；不符合就记下步骤和截图，回到开发会话排查。

前置：已执行当时指向 v2 的安装脚本（现为 `scripts\install-v3.ps1`）并重启 3080；浏览器打开
`http://127.0.0.1:3080`。

## 1. 视图与画图

- [ ] 打开任意有内容的会话 → 顶部出现「对话 / 轨迹 / **画板**」三个视图 tab。
- [ ] 切到「画板」：空白画板 + 提示"选择工具开始画"；工具栏含画板下拉、工具、颜色、
      AI、撤销/重做/清空、缩放、导出。
- [ ] 用「矩形」画两个框，用「文字」写一句话，用「画笔」划一笔，用「箭头」连一条线。
      期望：图形跟手；文字双击可编辑；箭头方向正确。
- [ ] 换颜色（红/绿/橙/accent）画一个。期望：新图形用该色。
- [ ] `Ctrl+Z` 撤一步、`Ctrl+Y` 重做；「清空」后画板为空（可撤销）。
- [ ] 缩放 `+/-` 与「适配」；抓手工具可平移。

## 2. 持久化与多画板

- [ ] 刷新页面（F5），重新打开该会话 → 画板内容还在（数据在 Host，不在 localStorage）。
- [ ] 画板下拉：新建「测试板」→ 自动切换过去且为空；画一笔；切回原板 → 原内容在；
      再切回「测试板」→ 那一笔还在。
- [ ] 重命名「测试板」为「验收板」；删除它 → 自动回到一张有效画板，列表不再有它。
- [ ] 打开另一个会话 → 它的画板是独立的（默认空板），不会串内容。

## 3. AI 一步闭环（核心）

> 请在助手**空闲**时操作（不要在其回复过程中发送）。

- [ ] 「选择」工具框选 2 个对象 → 选区浮层出现「AI 修改」。
- [ ] 点「AI 修改」→ 输入框出现；输入"把右边矩形改成红色，并在下面加文字「AI 添加」"；
      发送。期望：输入框关闭，工具栏显示 AI 处理中，可点「取消交给 AI」。
- [ ] 等待本轮结束（约 10–60 秒）：画板自动出现红色矩形 + 新文字；改动元素高亮约 2 秒，
      鼠标悬停显示「AI 修改」；顶部 toast 显示"AI 修改了 N 处"，带「撤销」。
- [ ] 点 toast「撤销」→ 改动消失（回到 AI 之前），其余内容不变。
- [ ] 再让 AI 只改颜色 → 完成后手动改同一个对象的颜色，确认人类操作不被 AI 覆盖
      （AI 提交是字段级合并）。
- [ ] 刷新页面 → AI 的改动（未被撤销的那次）仍在。

## 4. 导入 / 导出

- [ ] 工具栏 JSON 导出：下载 `画板名.json`；打开确认含 `elements`。
- [ ] JSON 导入：选择刚导出的文件 → 当前画板内容被替换（作为一次可撤销变更）；
      撤销可回到导入前。
- [ ] PNG 导出：下载图片，内容与画板一致。

## 5. 多标签同步

- [ ] 同一会话在两个浏览器标签打开「画板」：A 标签画一笔，B 标签 1 秒内出现。
- [ ] A 标签让 AI 改动，B 标签看到同样的高亮与 toast（各自可撤销自己的视图状态）。

## 6. 回滚演练（可选，2 分钟）

- [ ] `powershell -ExecutionPolicy Bypass -File scripts\rollback-v1.ps1` → 重启 3080
      → 打开会话：回到 v1 的「画板」面板（顶部主视图面板），v1 数据仍在。
- [ ] 当时的 `scripts\install-v2.ps1`（现为 `install-v3.ps1`）→ 重启 3080 → 回到 v2 视图；v2 画板数据仍在。

## 7. 断崖式更新确认

- [ ] v2 中**不再出现** v1 时期的面板内容（旧 localStorage 数据不读取、不删除）。
      这是已确认的破坏式更新，不是 bug。
