# 事后复盘

[English](README.md) | 中文

事故记录：一个 bug 到达了它本不该到达的地方，例如发布版本、已合并的变更或用户数据。其中真正有价值的部分是*我们的流程为什么放过了它*，而不只是一行修复。

事后复盘不是 [Agent Note](../../.agents/notes/README.zh.md)（后者记录有意的设计决策及其被否决的替代方案，或提出未来工作）。它是对失败的回溯记录：什么坏了、机制是什么、每一道安全网为什么都没拦住，以及新增了哪些具体护栏，使同类 bug 下次会响亮地失败。

当 bug 具备以下特征时写一篇：**隐蔽**（机制不显然，认真的工程师也要费劲重新推导）、**系统性**（逃逸原因是测试、工具或约定的缺口，而不是一次性笔误）、**重新发现的代价高**（耗费了真实调试时间，并且还会再次耗费）。链接该复盘促成的护栏——测试、AGENTS.md 规则、Agent Note。

每篇复盘都以**执行摘要**开头：一段忙碌读者三十秒内能吸收的短文——什么坏了、用平实语言说明根因、为什么逃逸了、持久的教训——其后是详细的摘要／时间线／根因／护栏各节。

## 已记录的事后复盘

暂无。不要为了填充本节而编造事故；只有在真实失败满足上述条件后才新增文件。
