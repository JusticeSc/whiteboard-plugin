# Terminology

This glossary is the source of truth for both translation directions. Load it before translating a pair; each row fixes the Chinese rendering and the first-mention annotation. It is bilingual within one file and needs no separate counterpart.

After a Chinese first-mention annotation, use only the base term without repeating the gloss. A component term already annotated inside a longer term needs no repeated annotation when later used alone. Translate new terms only with the precedent required by [translation rules](translation-rules.md); otherwise retain English and list them as pending terms.
