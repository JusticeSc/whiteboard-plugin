# 双语文档

[English](README.md) | 中文

本页适用于已有中英文对应文件的治理文档，不要求翻译插件现有的单语产品文档。[翻译规则](translation-rules.zh.md)规定忠实性与结构要求；[术语表](terminology.md)提供共用术语。

## 配对规则

- 两种语言同权。任一侧都可以先撰写；在同一变更中更新对侧，并依据实际代码或产品文档解决事实分歧。
- 一对文档由同级的 `foo.md` 与 `foo.zh.md` 组成。语言切换行紧随 H1：英文侧为 `English | [中文](foo.zh.md)`，中文侧为 `[English](foo.md) | 中文`。
- 保持标题顺序与深度、列表与表格结构、命令与代码原文，以及等价的链接目标。链接目标有双语对应文件时使用同侧语言；单语产品文档保留原路径。
- 删除或改名时同时处理两侧及其入站链接。不要仅为满足继承的模板假设而创建对侧文件。

## 审查流程

1. 阅读本次变更所依据的产品事实与相关术语。
2. 更新两侧有变化的段落，保留未受影响的已审措辞。
3. 逐个语义成分比较执行者、条件、义务、例外、失败与副作用。
4. 检查语言切换行、标题、列表、表格、代码、相对路径与片段锚点。如实报告实际进行的审查与命令。

本包没有翻译配对生成器、hash 记录校验器、文档门禁或已安装的翻译钩子。适配后的治理页面不维护导入的 `.i18n.yaml` 记录；不得把这些记录当作一致性证据。活动检查仍以[测试策略](../testing.zh.md)与包清单为准。

## 范围与排除

此流程适用于保留的双语治理页面，包括贡献、安全、架构、开发、测试、防御性指导与本目录。除非请求的变更影响其事实，否则保留现有产品文档的语言与发布证据。

Agent 指令与技能可以仅用英文维护，术语表本身在一个文件内提供中英对照。已安装、生成与 vendor 目录不在撰写范围内。冻结的历史 Agent Note 不属于翻译维护对象；保留其内容与配套文件。

## 责任

负责撰写的作者直接更新对侧；可以选择另行委派翻译。人工审查确认语义等价，不代表远端 CI 已通过或发生了实际不存在的人工批准。未来若引入自动配对系统，必须显式修改工具，并由当前包清单与 CI 支持后，其命令才能成为必需步骤。
